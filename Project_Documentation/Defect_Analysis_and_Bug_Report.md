## 4. Bug Report Template

The following format will be used if a defect is identified in future testing.
   
| Field              | Description                                 |
|--------------------|---------------------------------------------|
| Bug ID             | Unique defect identification number         |
| Bug Title          | Short description of the issue              |
| Module             | Application module where the issue occurred |
| Environment        | Browser and operating system                |
| Preconditions      | Conditions required before testing          |
| Steps to Reproduce | Steps to reproduce the issue                |
| Expected Result    | Expected application behaviour              |
| Actual Result      | Observed incorrect behaviour                |
| Severity           | Impact of the defect                        |
| Priority           | Urgency of fixing the defect                |
| Status             | New, Open, Fixed, Retest or Closed          |
| Evidence           | Screenshot or recording, if available       |

Defect analysis was performed based on the recorded test execution results. No confirmed defects were identified during the current testing activity.
