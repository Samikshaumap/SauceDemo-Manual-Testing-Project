# SauceDemo Manual Testing Project

## Project Overview
This project focuses on manual testing of the SauceDemo e-commerce web application. The objective was to understand the application workflow, identify test scenarios, prepare test cases, execute tests, and document the results.

## Application Under Test
- **Application:** SauceDemo
- **Website:** https://www.saucedemo.com/
- **Testing Type:** Manual Testing
- **Project Type:** E-Commerce Web Application

## Modules Tested
- Login
- Product Display
- Product Sorting
- Shopping Cart
- Checkout
- Order Completion
- Logout

## Testing Activities
- Prepared a project test plan.
- Reviewed application requirements and workflow.
- Created test scenarios and test cases.
- Prepared test data.
- Performed test execution and documented results.
- Prepared defect analysis and a bug report template.
- Practised Oracle SQL queries.

## Tools Used
- Microsoft Excel – Test scenarios, test cases, and test data
- Markdown – Project documentation
- Oracle SQL – SQL practice
- Git and GitHub – Version control and project repository
